## Versioning rule

- Framework version identifies a kit release.
- Core document versions change when that document's normative content changes.
- Template versions change when their required fields/semantics change.
- A framework release may contain documents/templates whose individual versions differ.
- `CHANGELOG.md` describes semantic changes; this matrix answers exactly which artifact version ships in the kit.
